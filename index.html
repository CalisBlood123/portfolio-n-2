Cómo trabajo

Cómo desarrollo un proyecto

Sigo tres pasos para convertir una idea de diseño en una página web clara, ordenada y que funcione correctamente.

01

Idea y diseño

Primero entiendo qué necesita el proyecto y preparo un boceto en Figma para definir cómo se verá y cómo lo usarán las personas.

02

Estructura y estilos

Escribo el código HTML y CSS de forma ordenada, para que la página se vea bien en cualquier pantalla y sea fácil de mantener.

03

Funciones e interacción

Con JavaScript agrego funciones y animaciones sencillas, y conecto datos externos cuando el proyecto lo necesita.
